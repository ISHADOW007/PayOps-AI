# AGENTS.md

This repository's instructions for coding agents live in [`CONTRIBUTING.md`](./CONTRIBUTING.md). Read it fully before doing anything, then read `docs/PROGRESS.md`.

The same rules apply to every coding agent (Codex, Cursor, Copilot, Gemini CLI): stay in the current phase, never read or print `.env` values, models never touch the database or authorize actions, follow `docs/05-ui-design.md` for all UI, and update `docs/PROGRESS.md` at the end of each session.
